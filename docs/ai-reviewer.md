# AI Reviewer

AI Reviewer запускается через GitHub Actions после успешного `Playwright CI` и анализирует изменения в Pull Request.

Reviewer использует:

* `CODEX.md` — правила разработки и тестовой архитектуры;
* `REVIEW.md` — чеклист код-ревью;
* diff текущего Pull Request;
* AI-модель через API.

Результат публикуется непосредственно в Pull Request как GitHub review.

## Что проверяет AI Reviewer

Reviewer анализирует:

* структуру и архитектуру автотестов;
* соответствие `CODEX.md`;
* использование Page Object и helpers;
* расположение тестов и вспомогательного кода;
* локаторы;
* `test.step`;
* тестовые данные;
* ожидания и синхронизацию;
* наличие `sleep`, `force`, `.only` и необоснованных таймаутов;
* подготовку и очистку тестовых данных;
* качество и читаемость изменений.

Reviewer может оставить замечания непосредственно на добавленных строках diff.

## Как работает workflow

1. Pull Request проходит `Playwright CI`.
2. После успешного CI запускается AI Reviewer.
3. Workflow получает diff Pull Request через GitHub API.
4. В AI-модель передаются diff и правила из `CODEX.md` и `REVIEW.md`.
5. AI Reviewer формирует потенциальные замечания.
6. Замечания проходят дополнительную проверку на ложные срабатывания.
7. В Pull Request публикуется итоговый review.

AI Reviewer анализирует только изменения текущего Pull Request и не запускает код из Pull Request внутри workflow.

## Безопасность

API-ключ для AI Reviewer хранится в GitHub Actions Secrets и не находится в репозитории.

AI-модель не получает GitHub token и не выполняет действия непосредственно в репозитории.

Публикацию review выполняет GitHub Actions с использованием стандартного GitHub token.

Секреты, токены и другие чувствительные данные не должны добавляться в исходный код, workflow или документацию.

## Ограничения

AI Reviewer не заменяет ручное код-ревью.

Автоматическая проверка может:

* пропустить реальную проблему;
* предложить замечание, которое не требует исправления;
* неправильно интерпретировать бизнес-логику;
* не учитывать контекст, отсутствующий в diff.

Поэтому замечания AI Reviewer используются как дополнительный инструмент контроля качества.

## Конфигурация

Для работы AI Reviewer используется GitHub Actions workflow:

```text
.github/workflows/ai-review.yml
```

API-ключ для выбранного AI-провайдера хранится в GitHub repository secrets.

Конфигурация workflow, правила ревью и код AI Reviewer находятся непосредственно в этом репозитории.
